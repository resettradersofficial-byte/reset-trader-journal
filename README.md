# RESET TRADER PWA V3

Zero-cost, offline-first version of the RESET TRADER Daily Behavioral Journal.

## Files
- `index.html` — app
- `manifest.webmanifest` — install/app metadata
- `sw.js` — offline cache
- `icons/` — app icons

## Deploy free with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Open the HTTPS Pages URL on Android Chrome.
5. Use the `INSTALL APP` button when available, or Chrome menu → Add to Home screen / Install app.

## Privacy model
Journal entries are stored in browser `localStorage` on the device. No database or server is used by this app. Do not put exported journal JSON files into the GitHub repository.
