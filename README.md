# RESET TRADER V4

Account-enabled PWA using Firebase Authentication and Cloud Firestore.

## Firebase setup
1. Enable Google and Email/Password in Authentication.
2. Create a Cloud Firestore database.
3. Publish the rules in `firestore.rules`.
4. Deploy the contents of this folder to GitHub Pages.

The Firebase web config is included in `index.html`; Firebase web API configuration is not a secret. Keep server/service-account credentials private.
